# DeepSeek 桌宠 · 像素小鲸鱼

一只住在桌面上的蓝鲸。会游、会掉、会被抓起来挣扎、摔狠了会晕。

## 跑起来

```bash
cd "C:\Users\lin\Desktop\林九\桌宠"
npm start
```

退出：托盘图标右键 → 退出（窗口是全透明的，看不见边框）。

## 现在会什么（v0.1 · 壳）

- 铺满全屏的透明窗口，鼠标默认穿透，只有指到鲸鱼身上才接管
- 重力：从高处掉下去，落狠了会头晕冒星星
- 自己在屏幕上左右游，会眨眼、尾巴摆、眼睛跟着鼠标转
- 按住能拖走：挣扎、冒汗、喊「放我下来」
- 双击弹起来「噗——」一声
- 气泡说话
